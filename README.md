# 中国工商银行外部数据产品管理平台

本项目展示外部数据产品从资源准备、能力建设、模块组装到产品发布和业务应用的完整过程。界面数据均为演示数据，不连接真实银行系统或生产数据。

## 运行与构建

需要 Node.js 20 及以上版本。执行 `npm install` 安装依赖，执行 `npm run dev` 启动本地环境，执行 `npm run build` 生成生产版本。建议使用 1440×900 或更高分辨率。

## 建设管理门户

主流程为：资源准备 → 需求受理 → 能力建设 → 模块组装 → 测试发布 → 成品管理。

- 资源准备：接入外部数据，核对字段、口径、授权和重复情况。
- 需求受理：明确业务任务、适用范围、交付结果和建设边界。
- 能力建设：定义模块用途、输入、处理条件、输出和测试样本。
- 模块组装：按业务先后关系组合模块，检查前后数据能否衔接。
- 测试发布：完成数据、功能和业务验证后提交审批。
- 成品管理：查看正式版本、适用范围、组成清单和调用入口。

## 分行建设与报送门户

主流程为：明确任务 → 选择资源 → 试运行 → 在线报送 → 查看进度。分行可以调用已有资源和能力，也可以登记本地新增模块。报送档案包含业务任务、数据来源、处理过程、输出结果、适用范围和地方依赖。

## 业务应用门户

主流程为：明确任务 → 选择产品 → 查看依据 → 设置参数 → 结果与行动。业务人员可按场景选择产品，了解数据来源和适用边界，设置地区、行业、期限和风险条件，生成产业分析、经营变化、融资机会、风险提示及后续行动。

## 演示案例

预置案例为“半导体企业扩产融资机会与风险分析产品”。建设端新增扩产事件识别能力，将项目备案、厂房建设和设备招标等信息转化为可解释的扩产阶段与判断依据；随后与主体关联、产业链定位、融资需求研判和风险核验等能力按业务顺序组装，经过验证后发布为标准产品。

关键演示状态保存在浏览器 `localStorage` 中，刷新后仍会保留。清除当前站点的浏览器本地存储即可恢复初始状态。

## 主要目录

- `app/`：页面、样式和演示数据
- `public/`：图片和图标资源
- `行内部署说明.md`：部署环境、运行命令和验收步骤
- `功能说明.md`：门户流程及功能边界
- `数据说明.md`：演示数据范围和安全边界

技术构成：Next.js、React、TypeScript、Ant Design、ECharts、dnd-kit。
